# Ruffy Visuals (Minecraft 1.21.11)

## Download and install

1. Open the repository's **Actions** tab.
2. Select the latest successful **Ruffy Visuals Build** run.
3. Download the `ruffy-visuals-1.21.11` artifact and extract it.
4. Put `ruffy-visuals-1.1.1.jar` into `.minecraft/mods`.
5. Start Minecraft 1.21.11 with Fabric Loader 0.18.4+ and Fabric API 0.141.1+1.21.11 installed.
6. In a world, press **Right Shift** to open the futuristic control center.

The Effects section contains toggles for Smooth Swing, Impact Slash, Air Sparks, Landing Ring, Sprint Dust, Movement Trail, Jump Burst and Nebula Particles.

## Build locally

Install Java 21 and Gradle 9.2.1+, then run:

```bash
gradle build
```

The JAR is generated in `build/libs/`.
